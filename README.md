# LoopCam Frames

Overlay frames for the LoopCam video app: 44 designs in four ratios (9:16 1080×1920, 16:9 1920×1080, 4:5 1080×1350, 1:1 1080×1080).

Live gallery: https://mdecides-design.github.io/loopcam-frames/

- Every SVG has a transparent window. `<path id="video-window">` marks where the video goes.
- Frame colours are listed in the root `data-colors` attribute and in `frames.json`. To recolour, replace a hex value everywhere it appears in the file.
- `LoopCam_Frames_SVG.zip` contains every frame.
